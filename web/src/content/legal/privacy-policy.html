一、定义与解释

1. 词元工厂服务

指灵鲸科技向您提供的 AI API 网关、密钥管理、用量计费、管理控制台、开发者工具及相关增值服务。

2. 账号

指您完成注册后使用的用户账号，以及与之关联的 API 密钥、访问令牌等凭证。您应妥善保管账号及凭证，并对账号下的行为负责。

3. 个人信息

指以电子或其他方式记录的能够单独或者与其他信息结合识别特定自然人身份或反映特定自然人活动情况的各种信息。

4. 个人敏感信息

指一旦泄露、非法提供或滥用可能危害人身和财产安全，极易导致个人名誉、身心健康受到损害或受到歧视性待遇的个人信息，例如身份证件号码、银行账号、通信内容等。

5. 日志信息

指您使用服务时系统自动记录的技术信息，例如 IP 地址、浏览器类型、访问时间、请求路径、错误日志及 API 调用记录等。

二、我们如何收集和使用您的个人信息

1. 我们收集的信息类型

为实现平台功能、保障服务安全及履行法定义务，我们可能收集以下信息：

  • 账号信息：用户名、邮箱、手机号码、密码哈希、头像及您主动填写的个人资料；
  • 身份验证信息：用于登录、找回密码、二次验证及 OAuth 第三方登录所需的必要信息；
  • 交易与计费信息：充值记录、订单信息、支付方式、发票信息及配额使用情况；
  • API 使用信息：API 密钥标识、模型调用记录、Token 用量、请求参数摘要、响应状态及错误信息；
  • 设备与日志信息：IP 地址、浏览器类型、操作系统、访问时间、Referer、Cookie 及安全审计日志；
  • 您主动提交的内容：您在 Playground、工单、反馈或客服沟通中提交的文字、文件及其他信息。

2. 我们如何使用信息

  • 为您创建和管理账号，提供 API 网关、计费、控制台等核心功能；
  • 验证身份、保障账号与 API 密钥安全，防范欺诈、滥用及攻击行为；
  • 统计和分析服务使用情况，优化产品性能与用户体验；
  • 处理充值、结算、开票及与您相关的客户服务；
  • 向您发送服务通知、安全提醒及依法需要告知的信息；
  • 遵守法律法规、监管要求及配合有权机关依法提出的要求。

3. 第三方 SDK 与服务

为实现支付、存储、身份验证等功能，我们可能接入第三方服务。相关第三方仅在实现功能所必需的范围内处理信息：

服务类型 使用目的 可能涉及的信息

对象存储/CDN 存储头像、附件及静态资源 您上传的文件及相关元数据

我们使用 Cookie、LocalStorage 及类似技术以保障登录状态、记住偏好设置、统计访问情况并提升安全性。您可通过浏览器设置管理或删除 Cookie，但可能影响部分功能的使用体验。

四、我们如何共享、转让、公开披露您的个人信息

1. 共享

我们不会出售您的个人信息。仅在以下情形下，我们可能共享必要信息：

  • 经您明确同意或授权；
  • 为完成支付、身份验证、云存储等功能，向合作服务商提供必要信息；
  • 为履行法律法规、诉讼、仲裁或政府主管部门强制性要求；
  • 为保护您、我们或其他用户的合法权益所合理必需的情形。

2. 转让

如发生合并、收购、重组或破产清算，您的个人信息可能随之转移。我们将要求继受方继续受本政策约束，或重新征得您的授权同意。

3. 公开披露

我们仅会在获得您明确同意，或基于法律规定、合法新闻披露等法定情形下公开披露您的个人信息。

我们采用行业通行的安全防护措施保护您的个人信息，包括但不限于传输加密（HTTPS/TLS）、访问控制、权限分级、日志审计及安全事件响应机制。尽管我们已采取合理措施，但互联网环境并非绝对安全，请您妥善保管账号、密码及 API 密钥，避免向他人泄露。

如发生个人信息安全事件，我们将按照法律法规要求及时向您告知事件情况、处置措施及补救建议，并按规定向监管部门上报。

1. 存储地点

原则上，我们在中华人民共和国境内收集和产生的个人信息，存储在境内服务器。如需跨境传输，我们将依法履行评估、告知及征得同意等义务。

2. 存储期限

我们仅在实现本政策目的所必需的期限内保留您的个人信息，除非法律法规要求或允许更长的保留期。账号注销后，我们将依法删除或匿名化处理您的个人信息，但法律法规另有规定或为履行合规义务所必需的除外。

为计费、排错及安全审计，我们可能短期保留 API 调用日志。涉及转发至上游 AI 服务商的请求内容，将同时受上游服务商数据处理规则约束。
